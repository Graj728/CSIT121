Lab 3

Published on September 24, 2026 by Gaurav Raj Sah

For my third webpage, I built on the structure from Lab 2 and worked on styling it with CSS. Instead of writing styles directly in the HTML, I linked an external stylesheet, which kept my HTML file clean and made it much easier to update the look of the whole page from one file.

What I Learned

  1. How to link an external stylesheet using the <link> tag
  2. How to style elements using type selectors, such as body, headings, paragraphs, and links
  3. How to style a single or unique element with an ID selector
  4. How to reuse a style across multiple elements with a class selector
  5. How to validate CSS using the W3C CSS Validator
